# 🎓 Student Success Dashboard

A comprehensive student dashboard built using **HTML & CSS** to help students track academics, coding progress, internships, projects, achievements, and career growth in one place.

## 🚀 Live Demo:
https://studentsuccessdashboard.netlify.app/

 GitHub Pages Repository:
 https://debugwithyash.github.io/STUDENT-SUCCESS-DASHBOARD/


## 📌 Features

### 👤 Student Profile

* Personal information
* Academic details
* Project count
* Hackathon participation

### 📊 Academic Overview

* CGPA Tracking
* Attendance Monitoring
* Projects Overview
* Hackathon Statistics

### 📈 Progress Tracking

* Attendance Tracker
* Coding Skills Progress
* Learning Roadmap

### 🚀 Internship Tracker

* Applied Companies
* Internship Status
* Career Progress

### 🏆 Achievements Section

* Hackathons
* Projects
* Learning Milestones

### 📚 Study Management

* Subjects List
* Weekly Study Timetable
* Daily Goals Checklist

### 💻 Developer Section

* GitHub Statistics
* Project Showcase
* Certificates

### 🌐 Social Links

* GitHub
* LinkedIn
* Instagram
* Email Contact
